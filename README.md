# dbt Analytics Engineering

A hands-on dbt learning portfolio built on DuckDB. Each folder is its own dbt project.

| # | Project | Focus |
|---|---------|-------|
| P01 | TPC-H Foundations | sources, staging, marts, tests, docs |
| P02 | Campaign Mart | star schema, SQL window functions |
| P03 | History Tracking | snapshots, incremental models |
| P04 | Traffic Quality Signature | macros, custom tests (synthetic data) |
| P05 | Metrics + CI | metrics layer, GitHub Actions, dashboard |
